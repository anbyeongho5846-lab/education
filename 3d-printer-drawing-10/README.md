# 3D프린터운용기능사 공개도면 ⑩ – 2D 도면 → 3D 모델

손글씨 메모가 있는 공개도면 ⑩ 사진을 보고 다시 만든 결과물입니다. 단위는 mm입니다.

## 결과물 (`output/`)
| 파일 | 내용 |
|---|---|
| `part1.stl`, `part2.stl` | 부품 ①, ② 출력용 STL ("01" 음각은 부품 ①에 포함) |
| `assembly.stl` | 조립 상태(부품 ②의 크로스바 아랫면이 보스 윗면 Z=14에 닿는 위치) |
| `part1.step`, `part2.step` | Onshape나 다른 CAD로 가져올 수 있는 솔리드 모델 |
| `drawing.dxf` | 2D 도면(AutoCAD R2018 DXF): 부품 ① 평면도와 단면 A-A, 부품 ② 정면도와 평면도, 치수 |
| `drawing.pdf`, `drawing.png` | 도면 미리보기 |
| `preview_3d.png` | 3D 렌더링 미리보기 |

## 적용한 치수와 해석
**부품 ①**: Ø16 보스(높이 14), Ø8 관통 구멍, 아래쪽 Ø12 카운터보어(깊이 4), 몸체와 링 높이 10(ㄱ),
중심거리 33, R15 외곽, Ø20 관통 구멍 + C3 모따기, R10.5~R17.5 원호 홈(깊이 3), 2-R1 필렛

**부품 ②**: 위쪽 축 Ø10(ㄴ, 크로스바 위로 9, 끝 R3), 크로스바 폭 6(ㄹ)·두께 5, 다리 R11~R17(왼쪽 12, 오른쪽 7),
아래쪽 축 A=Ø8, B=10, 칼라 Ø12×3

- A=8과 칼라 Ø12는 사진의 손글씨 메모를 따랐습니다.
- B=10은 부품 ① 보스에서 Ø8 구멍 길이(14−4)로 정했습니다. 메모 화살표가 단면도의 10 쪽에서 B로 이어진 것으로 읽었습니다.
- 두 부품 사이 틈새는 0으로 두었습니다(간섭 체적 0). 실제로 출력해서 조립하거나 돌려야 한다면 A나 B에 틈새를 주어야 할 수 있습니다.
- "01" 각인은 도면에 치수가 없어서 글자 높이 5, 깊이 0.5로 임의로 정했습니다.

## 다시 생성하기
```bash
python -m venv venv && ./venv/bin/pip install cadquery ezdxf matplotlib
```
```bash
mkdir -p out && ./venv/bin/python source/build.py out
```
```bash
./venv/bin/python source/drawing.py source out/drawing.dxf
```
